Growth Roadmap

Fifteen production-grade projects, sequenced from foundations to elite differentiators — each expanded into a concrete execution plan with milestones, a stack, deliverables, and the résumé line it unlocks.

15 projects 4 tiers Target: Generative AI / AI Engineer Edge: Geospatial & Multimodal AI

How to use this roadmap

This is a build order, not a wishlist. Work top-down: Tier 1 is non-negotiable — it covers the table-stakes an AI Engineer screen filters on. Each tier after that raises your ceiling. You don't need all fifteen; finishing Tier 1 fully, plus a selective sweep through Tiers 2–4, beats fifteen half-built repos.

For every project: ship a clean GitHub repo with a real README (problem → architecture diagram → results), capture the metrics as you build (latency, throughput, eval scores, cost saved — these become your résumé numbers), and record a 60–90s demo. Tick the box on a card when it's genuinely portfolio-ready. Your progress persists locally when you save this file.

Priority pick if you only do five: the RAG system, the multi-agent build, the multimodal geospatial project (your unique edge), the inference/serving work, and a full LLMOps pipeline. That set maps cleanly onto almost every AI Engineer job description.

Essential Projects

PROJECT 01 / 15

Production RAG System with Evaluation

Hybrid retrieval over a real corpus, reranked and measured — the project that proves you can build retrieval that actually works, not a toy.

~2 weeks RAGVector DBEvaluation
+

Execution milestones

  1. Ingest a domain corpus (agriculture / enterprise docs ties to your work); experiment with chunking strategies and overlap.
  2. Stand up hybrid search: BM25 + dense embeddings in pgvector or Qdrant; tune the fusion weighting.
  3. Add a cross-encoder reranker and measure the lift it buys you.
  4. Wrap it in a FastAPI service with streaming responses and citation of source chunks.
  5. Build a RAGAS / DeepEval harness reporting faithfulness, answer relevance, and context precision.

Deliverables & metrics

  • GitHub repo + architecture diagram in the README.
  • Eval scorecard: faithfulness / relevance before vs after reranking.
  • Retrieval latency (p50/p95) and end-to-end answer latency.
  • A short demo querying the corpus live.
